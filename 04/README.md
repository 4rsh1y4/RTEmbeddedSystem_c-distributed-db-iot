## ۱. نحوه نصب بسته‌های SNMP
برای راه‌اندازی این بخش، به دیمن اصلی SNMP (`snmpd`) و ابزارهای کلاینت آن (`snmp`) نیاز است. نصب این بسته‌ها در توزیع‌های دبیان/اوبونتو با دستور زیر انجام می‌شود:
<div dir="ltr">

```bash
sudo apt update
sudo apt install -y snmpd snmp
```

</div>

## ۲. نحوه پیکربندی `snmpd`
تنظیمات این سرویس در فایل `/etc/snmp/snmpd.conf` قرار می‌گیرد. در این پروژه، ما فایل `snmpd.conf` را برای ایجاد یک دسترسی فقط‌خواندنی (`public`) و استفاده از قابلیت `pass` جهت اتصال OIDهای سفارشی به اسکریپت Bash پیکربندی کرده‌ایم. 
*(نکته: در اسکریپت `build_and_run.sh` این پیکربندی به صورت کاملاً خودکار انجام می‌شود).*

## ۳. ساختار OID های تعریف‌شده
به منظور رعایت استانداردهای مدیریت شبکه و شخصی‌سازی پروژه، از شماره دانشجویی `402170562` به عنوان Enterprise ID استفاده شده است:
*   **Base OID:** `.1.3.6.1.4.1.402170562`
*   **Sensor ID:** `.{id}` (مثلاً 101, 204)
*   **Attributes:**
    *   `.1` : نام سنسور (Sensor Name)
    *   `.2` : توضیحات سنسور (Description / Unit)
    *   `.3` : آخرین مقدار ذخیره‌شده سنسور (Value)

## ۴. نحوه اجرای سرویس SNMP
سرویس `snmpd` یک دیمن پس‌زمینه در لینوکس است. پس از نصب و تنظیم فایل کانفیگ، با دستور زیر راه‌اندازی مجدد و اجرا می‌شود:
<div dir="ltr">

```bash
sudo systemctl restart snmpd
```

</div>

## ۵. نحوه خواندن اطلاعات با `snmpwalk`
برای خواندن مقادیر یک شاخه به صورت بازگشتی، از ابزار `snmpwalk` استفاده می‌شود:
<div dir="ltr">

```bash
snmpwalk -v2c -c public localhost .1.3.6.1.4.1.402170562
```

</div>

## ۷. توضیح مسیر دریافت داده (از پایگاه داده تا خروجی SNMP)
معماری این سیستم به گونه‌ای طراحی شده که مانیتورینگ کاملاً با لایه‌ی توزیع‌شده یکپارچه باشد:
1.  کاربر دستور `snmpwalk` را اجرا می‌کند.
2.  سرویس `snmpd` درخواست را دریافت کرده و با استفاده از دایرکتیو `pass`، اسکریپت `snmp_extension.sh` را اجرا می‌کند.
3.  اسکریپت Bash به جای اتصال مستقیم به دیتابیس (که باعث نقض کپسوله‌سازی می‌شود)، یک درخواست HTTP حاوی ID سنسور به API مستر ارسال می‌کند.
4.  نود Master درخواست را پردازش کرده و داده را (بسته به موقعیت سنسور) از **کش Memcached**، **دیتابیس SQLite لوکال** یا **از طریق شبکه از نودهای Slave** استخراج کرده و به صورت JSON برمی‌گرداند.
5.  اسکریپت، JSON را پارس کرده و به فرمت استاندارد SNMP چاپ می‌کند تا توسط `snmpwalk` به کاربر نمایش داده شود.
