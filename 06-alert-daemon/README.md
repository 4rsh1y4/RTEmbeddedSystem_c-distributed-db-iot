## ۱. معرفی ماژول و معماری
در این بخش از پروژه، قابلیت واکشی لاگ‌های سنسورها به هسته مرکزی اضافه شده است. این سیستم با استفاده از کتابخانه Mongoose در زبان ++C توسعه یافته و به صورت مستقیم با پایگاه داده SQLite ارتباط برقرار می‌کند تا مقادیر ثبت‌شده‌ی یک سنسور خاص را در یک تاریخ مشخص به صورت یک REST API ارائه دهد.

## ۲. ساختار پایگاه داده و مقداردهی اولیه
برای تست این API، نیازی به ایجاد جداول جدید نبود؛ بلکه از معماری رابطه‌ای موجود (جداول sensors و sensor_readings) استفاده شد.
اسکریپت `scripts/master_init_db.sh` به‌گونه‌ای توسعه یافته است که علاوه بر ساختار اصلی، داده‌های تستی خواسته‌شده در صورت پروژه را به صورت خودکار به پایگاه داده تزریق می‌کند.

## ۳. نحوه کامپایل
کد نوشته‌شده در `main.cpp` به همراه کتابخانه Mongoose نیاز به کامپایل دارد. فایل Makefile موجود در سیستم، با استفاده از کامپایلر g++ و فلگ‌های مناسب، سورس‌کد را به همراه کتابخانه‌های sqlite3، memcached و mosquitto کامپایل کرده و فایل اجرایی سیستم را می‌سازد.

## ۴. نحوه اجرا
مانند بخش‌های قبل، تمامی مراحل شامل متوقف کردن سرویس‌های قبلی، مقداردهی دیتابیس، کامپایل و اجرای سرور در یک اسکریپت خودکار تجمیع شده است. کافیست دستورات زیر را اجرا کنید:

```bash
cd 05/scripts
./build_and_run.sh
```

## ۵. نحوه تست API
پس از اجرای موفق سرور، در یک ترمینال جدید می‌توانید با ابزار curl درخواست خود را ارسال کنید. 
**توجه:** در دستور زیر، حتماً مقدار `192.168.54.136` را با آی‌پی واقعی نود Master شبکه خود جایگزین کنید.

```bash
curl "http://192.168.54.136:8080/api/logs?sensor_name=temperature&sensor_id=101&date=2026-06-01"
```

## ۶. مستندات مسیرها و پارامترها
* **مسیر:** `/api/logs`
* **متد:** `GET`
* **پارامترهای ورودی:**
  * `sensor_name`: نام سنسور
  * `sensor_id`: شناسه یکتای سنسور
  * `date`: تاریخ مورد نظر با فرمت YYYY-MM-DD

## ۷. ساختار خروجی
سیستم کوئری‌های دیتابیس را به صورت سطر به سطر پردازش کرده و یک شیء JSON استاندارد تولید می‌کند. نمونۀ خروجی موفق:

```json
{
  "sensor_name": "temperature",
  "sensor_id": "101",
  "date": "2026-06-01",
  "values": [
    {
      "time": "10:00:00",
      "value": "24.2"
    },
    {
      "time": "10:15:00",
      "value": "24.8"
    },
    {
      "time": "10:30:00",
      "value": "25.1"
    }
  ]
}
```
(نکته: در صورت عدم وجود رکورد در تاریخ مشخص‌شده، سیستم پیام خطای 404 در قالب JSON برمی‌گرداند).
